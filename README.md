# DescAI — ИИ-генератор описаний товаров

Веб-приложение на **React + Vite + TypeScript + Tailwind CSS** для генерации SEO-описаний товаров под маркетплейсы через **Google Gemini 3.8 Flash**.

## Возможности

- Ввод и хранение Gemini API ключа в `localStorage`
- Форма: название, маркетплейс, характеристики, тон, язык
- Генерация Markdown-описания с заголовком, буллетами, CTA и хэштегами
- **A/B тест**: сразу 2 разностилевых варианта
- **История генераций** в боковой панели (`localStorage`)
- **Лимиты символов** под Uzum / WB / Ozon / Avito / Kaspi
- **Пресеты категорий**: Одежда, Электроника, Косметика
- **Промпт для инфографики**: готовый текст под Gemini Image с размерами маркетплейса — скопировать и вставить с фото товара
- Быстрые правки: перегенерировать / короче / подробнее
- Тёмная и светлая тема

## Стек

- React 19, Vite, TypeScript
- Tailwind CSS 4
- `@google/genai`, `framer-motion`, `lucide-react`, `react-markdown`

## Запуск

```bash
npm install
npm run dev
```

1. Получите ключ в [Google AI Studio](https://aistudio.google.com/apikey)
2. Вставьте его в модальное окно приложения
3. Выберите шаблон или заполните форму и сгенерируйте описание

## Сборка

```bash
npm run build
npm run preview
```
